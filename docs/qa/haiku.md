# QA 보고서 (qa-engineer, haiku)

높음 1건, 중간 3건, 낮음 4건

코드를 고치지 않았고 프로젝트 폴더에 파일을 만들거나 고치지 않았다. 빌드와 시험은 복사본에서 실행했다. `.env`를 열지 않았고, DB와 실제 OpenRouter 호출도 하지 않았다.

## 높음

### H1. 위기 키워드가 흔한 위기 표현을 놓친다 (F5, S4)
- 위치: `lib/ai/crisis.ts:9-45`
- 놓침(false): "그만 살고 싶어", "죽었으면 좋겠다", "차라리 죽는 게 낫겠다", "죽어야겠다", "다 끝내고 싶다", "떠나고 싶다"
- 잡힘(true): "죽고 싶어", "사라지고싶다"
- 실제: AI 두 모델이 모두 실패하면 위기 카드가 나오지 않음
- 고칠 방향: "그만살고싶", "죽었으면", "죽어야", "죽는게낫" 등 추가와 시험. "끝내고싶", "떠나고싶"은 오탐 위험이라 사용자 판단

## 중간

### M1. 저장 뒤 응답이 실패하면 같은 일기가 중복 저장될 수 있다 (F2, F3)
- 위치: `app/api/entries/route.ts:24-32`, `components/api-client.ts:36-40`, `app/(pages)/write/page.tsx:41-44`
- 내용: 저장 뒤 반영 단계 DB 오류나 함수 시간 초과(504)면 "저장하지 못했어요"가 뜨지만 행은 이미 저장됨
- 고칠 방향: 저장 뒤 실패는 201과 `aiStatus: "failed"`, 클라이언트는 JSON이 아닌 응답을 따로 처리

- 고칠 방향: 사용자별 짧은 시간 창 제한 검토, 정책은 사용자가 승인

### M3. 모델 시간 제한이 PRD 기준(모델당 15초)과 다르고 최악 대기가 50초다 (F3, S2)
- 위치: `lib/ai/index.ts:13-14`, `tests/ai.test.ts:112`
- 고칠 방향: 시간 제한 값을 정하고 상수와 시험을 맞춤. Vercel 함수 한도 확인 필요

## 낮음

- L1. 글자 수를 UTF-16 단위로 센다(이모지 101개가 202자로 거부됨). `lib/entry-service.ts:14`, `write/page.tsx:71, 82`
- L2. 화면 문구가 PRD 4.4, 4.6과 다르다(의도한 변경). 빈 입력 때 "한 줄을 적어 주세요."는 단추가 비활성이라 나오지 않음(`write/page.tsx:87`)
- L3. 입력이 프롬프트 태그 `</diary>`를 닫을 수 있다(`lib/ai/prompt.ts:20`). 키워드 검사에는 영향 없음
- L4. "투신" 키워드가 "투신사 면접 봤다"에도 걸린다(`lib/ai/crisis.ts:42`)

## 확인한 것

- 시험 61개 통과, `npm run build`, `npm run lint`, `tsc --noEmit` 통과
- 로그인 없이 curl: `/` 200, 보호 화면은 307로 `/`, 모든 API는 401 JSON, `/api/auth/session`은 null, 로그인 오류 문구 표시
- 모든 DB 조건에 `user_id`, 매개변수 쿼리, 남의 일기 404, DB 오류는 일반 500
- 로그에는 `e.name`과 일기 번호만, 본문은 남기지 않음
- `NEXT_PUBLIC_` 없음, git 이력에 키 형식 없음, `.env`는 추적되지 않음
- AI 실패 경로(429, 빈 content, 잘못된 JSON, 시간 초과, fetch 예외, 키 없음)는 모두 `aiStatus: failed`

## 확인하지 못한 것

실제 구글 로그인과 로그아웃 뒤 뒤로 가기, 실제 OpenRouter 동작, 실제 Supabase 저장과 조회, 375px 렌더링, Vercel 함수 시간 한도
